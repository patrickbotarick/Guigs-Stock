## Demonstração no PC da loja

Pré-requisitos usados nesta máquina: Node 24, PostgreSQL 17.11 e os binários locais GoTrue e PostgREST. A demonstração cria um cluster descartável em loopback com usuários e dados fictícios. O navegador recebe um adaptador local.

```powershell
Set-Location 'C:\Projetos_VS_code\Guigs Stock - v1.9'
$tooling = Join-Path $env:LOCALAPPDATA 'GuigsStock-v19-local'
$env:GUIGS_TEST_PG_BIN = 'C:\Program Files\PostgreSQL\17\bin'
$env:GUIGS_TEST_AUTH_EXE = Join-Path $tooling 'auth.exe'
$env:GUIGS_TEST_POSTGREST_EXE = Join-Path $tooling 'postgrest.exe'
$env:GUIGS_ROUND1_WORK = Join-Path $tooling 'evidence'
node tests/v18-round1-postgres.cjs --demo
```

Abra as URLs que o terminal imprimir para `?role=owner` ou `?role=attendant`. Use `Ctrl+C` para encerrar. A pasta de evidências deve ficar fora do Git. A publicação depende de autorização separada.
