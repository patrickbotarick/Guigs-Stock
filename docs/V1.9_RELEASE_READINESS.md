## Demonstração com dados artificiais

Pré-requisitos já disponíveis nesta máquina: Node.js 24, PostgreSQL portátil 17.11, GoTrue e PostgREST usados na homologação local v1.8. O comando cria um banco e usuários descartáveis em loopback. O navegador recebe apenas um adaptador para o PostgREST local. Credenciais de serviços reais e `config.js` do checkout original não são usados.

```powershell
Set-Location 'E:\Projetos_VS_Code\Guigs-Stock-v19'
$env:GUIGS_ROUND1_WORK = 'E:\Projetos_VS_Code\guigs-v19-evidence'
New-Item -ItemType Directory -Force -Path $env:GUIGS_ROUND1_WORK | Out-Null
$tooling = 'E:\Projetos_VS_Code\guigs-v18-round1-02193b3\tooling'
$env:GUIGS_TEST_PG_BIN = Join-Path $tooling 'pgsql\bin'
$env:GUIGS_TEST_AUTH_EXE = Join-Path $tooling 'auth.exe'
$env:GUIGS_TEST_POSTGREST_EXE = Join-Path $tooling 'postgrest.exe'
node tests/v18-round1-postgres.cjs --demo
```

Abra os endereços exibidos no terminal. São `http://127.0.0.1:<porta>/?role=owner` e `http://127.0.0.1:<porta>/?role=attendant`. Use Ctrl+C para encerrar a sessão. Para uma cópia extraída do ZIP em outro diretório, ajuste o primeiro comando. O ambiente de teste deve continuar fora de qualquer repositório.

A candidata se destina à revisão visual e operacional. A publicação exige decisão separada do responsável. O checkout original mantém seus arquivos locais, e a comparação com a base não apresenta mudanças em `supabase/`.
